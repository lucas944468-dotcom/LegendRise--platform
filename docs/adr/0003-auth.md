# ADR-003: Authentication

- Status: Accepted (founder decision, 2026-09-26)
- Context: PRD FR-001 needs email sign-up/login, verification, reset, profile. No Supabase Auth.

## Decision

**Better Auth with the Prisma adapter.** Email/password + email verification
(via Resend; dev fallback logs the link). Sessions verified server-side on every
protected load/route (`src/lib/access.ts`: `requireUserId`, `requireAdminId`).
Secrets via `$env/dynamic/private`, available to Netlify Functions at runtime.
The server instance initializes lazily on the first runtime request and is reused
within that process. Build-time module analysis and the build-time hook do not
initialize authentication. Missing runtime configuration fails closed without
falling back to a default or generating a replacement secret.

## Consequences

- Better Auth 1.7 requires **zod v4** (project pins `^4.5.4`).
- Social logins deferred (Phase 4+).
- Admin flag (`User.isAdmin`) gates `/admin` (Phase 8).
