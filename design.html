4 · Responsive, accessibility & build notes

  • Breakpoints: mobile < 640px (single column) · tablet 640–1024px (2 col) · desktop > 1024px (3 col). Core journey works on desktop and mobile web before any native app.
  • Accessibility (WCAG 2.1 AA): labelled fields, focus-visible rings, Esc closes dialogs, role="progressbar/alert/dialog", live regions for dynamic updates, reduced-motion respected.
  • Framework: SvelteKit 2 + Svelte 5 (no React) · Database: local PostgreSQL 16 + Prisma · Accounts: Better Auth (email + verification) · Storage: Cloudflare R2.
  • Phases: P1 MVP one career → P2 depth → P3 Venture Lab + polish → P4 future. Current: Phase 3 build, journey verified on Postgres.
  • Prototype files: index.html (standalone clickable demo, no server) · design.html (this file).
